# Определение мастер-систем

При определении мастер-систем учтено, что MDM (Customer Hub) не может быть мастер-системой для всех сущностей. Финансовые (счета, транзакции) и продуктовые данные остаются в профильных банковских системах, а MDM предназначен для золотых записей клиентов и НСИ.

|Сущность|Источники As-Is|Мастер-система на 3 месяца|Целевая мастер-система|Связь с BIAN|Обоснование|
|-|-|-|-|-|-|
|**Участвующая сторона**|FU CRM, RB CRM|MDM Customer Hub|MDM Customer Hub|Party Data Management|Нужна золотая запись клиента, дедупликация и единый профиль для обеих CRM.|
|**Счет**|FU Core, RB Core|FU Core (для FU), RB Core (для RB)|Единая АБС (Core Banking)|Current Account / Savings Account|Счета — финансовые данные. MDM не должен управлять балансами. Требуется OLTP с ACID.|
|**Карта**|FU Cards, RB Cards|FU Cards, RB Cards|Единый карточный процессинг|Card Management|Управление статусами и лимитами карт остается в процессинге. Синхронизация через шину.|
|**Кредит**|FU Loans, RB Loans|FU Loans, RB Loans|Единая кредитная система|Loan Management|Кредитные портфели требуют единых правил скоринга и учета. Остаются в OLTP.|
|**Договор**|FU Core, RB Core|FU Core, RB Core|Единая АБС|Contract Management|Юридически значимые документы привязаны к счетам и кредитам. Управляются в АБС.|
|**Транзакция**|FU Core, RB Core|FU Core, RB Core|Единый транзакционный движок|Transaction Processing|Финансовая целостность. Транзакции не могут храниться в MDM.|
|**Платежный документ**|FU Core, RB Core|FU Core, RB Core|Единый платежный шлюз|Payment Order Management|Инициирование и проведение платежей — строго операционная функция.|
|**Продукт**|FU DWH, RB DWH|MDM (Product Catalog)|MDM (Product Catalog)|Product Catalog|Требуется единый каталог тарифов и продуктов для продаж и отчетности.|
|**Обращение**|FU CRM, RB CRM|FU CRM, RB CRM|Единая CRM|Customer Interaction|История обращений должна быть доступна в едином окне обслуживания клиента.|
|**Департамент**|FU CRM, RB CRM, HR|MDM|MDM|Branch Management|Оргструктура должна быть унифицирована для маршрутизации обращений и отчетности.|
|**Сотрудник**|FU CRM, RB CRM|MDM|MDM|Employee Management|Единый справочник сотрудников и ролей для разграничения доступа (RBAC).|
