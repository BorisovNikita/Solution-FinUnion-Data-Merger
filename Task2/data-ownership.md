# Правила владения данными (Data Ownership)

| Сущность | Data Owner (Бизнес-владелец) | Data Steward (Ответственный за качество) | Producer (Система/команда) | Consumer (Система-потребитель) | Правила изменения | Правила качества |
|----------|------------------------------|------------------------------------------|----------------------------|--------------------------------|-------------------|------------------|
| **Участвующая сторона** | Директор по розничному бизнесу | Data Office | CRM FinUnion, CRM RetailBank | MDM, DWH, BI, Контакт-центр | Только через MDM (после дедупликации) или CRM (с валидацией). | Проверка на дубли (ФИО+ИНН+Паспорт), валидация формата телефона, обязательность ИНН. |
| **Счет** | Финансовый директор | Главный бухгалтер | FU Core, RB Core | DWH, BI, MDM (для связи с клиентом) | Только через АБС (Core Banking) с правами администратора. | Контроль сходимости баланса, проверка валюты, запрет отрицательного баланса (кроме овердрафта). |
| **Карта** | Директор по карточным продуктам | Руководитель процессинга | FU Cards, RB Cards | DWH, BI, Поисковый движок | Только через карточный процессинг. | Валидация срока действия, проверка статуса (активна/заблокирована), сверка с АБС. |
| **Кредит** | Директор по рискам | Кредитный контролер | FU Loans, RB Loans | DWH, BI, MDM | Через кредитную систему с обязательным аудитом. | Проверка графика платежей, соответствие ставки продукту, контроль остатка долга. |
| **Договор** | Юридический директор | Руководитель юридического отдела | FU Core, RB Core | DWH, Объектное хранилище | Только через АБС с наложением ЭЦП. | Проверка наличия всех реквизитов, валидация дат, сверка сторон договора. |
| **Транзакция** | Финансовый директор | Главный бухгалтер | FU Core, RB Core | DWH, BI | Запрещено ручное изменение (только сторно/отмена через АБС). | Хэширование, контроль уникальности (ID), проверка соответствия суммы и назначения. |
| **Платежный документ** | Директор по операциям | Руководитель расчетного центра | FU Core, RB Core | DWH, BI | Через АБС, только авторизованные платежи. | Валидация БИК/ИНН получателя, антифрод-проверка, контроль лимитов. |
| **Продукт** | Директор по продуктам | Продуктовый менеджер | MDM (Product Catalog) | CRM, АБС, DWH, BI | Через MDM с версионностью (SCD2). | Проверка уникальности кода продукта, контроль ставок и тарифов. |
| **Обращение** | Директор контакт-центра | Руководитель службы поддержки | FU CRM, RB CRM | Единая CRM, DWH, Поисковый движок | Через CRM, обязательная фиксация статуса и канала. | Проверка на дубли обращений, обязательность темы и типа, валидация ПДн. |
| **Департамент** | HR-директор | Руководитель HR-отдела | HR-система | MDM, CRM, DWH | Через HR-систему с синхронизацией в MDM. | Уникальность кода подразделения, контроль иерархии, проверка региона. |
| **Сотрудник** | HR-директор | Руководитель HR-отдела | HR-система | MDM, CRM (для RBAC) | Через HR-систему, блокировка при увольнении. | Уникальность табельного номера, валидация ролей, проверка привязки к департаменту. |
