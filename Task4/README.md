# Task 4: План миграции, cutover и технологическая дорожная карта

## Описание решения

В рамках четвёртого задания разработан план перехода от As-Is к целевой архитектуре (Task 3). Определён образ целевого результата через 12 месяцев, составлен инкрементальный план из 7 этапов, подготовлен cutover-план для домена «Клиентские данные», описаны риски миграции и технологическая дорожная карта по зонам Adopt / Trial / Assess / Hold.

## Структура директории

* [**migration-target-state.md**](./migration-target-state.md) — описание целевого результата: что остаётся, что выводится, какие данные мигрируют.
* [**migration-plan.md**](./migration-plan.md) — инкрементальный план миграции (7 этапов).
* [**cutover-plan.md**](./cutover-plan.md) — детальный cutover-план для домена «Клиентские данные».
* [**migration-risks.md**](./migration-risks.md) — реестр рисков миграции с оценкой и митигацией.
* [**tech-roadmap.md**](./tech-roadmap.md) — технологическая дорожная карта (Adopt / Trial / Assess / Hold).
* [**diagrams/migration\_timeline.puml**](./diagrams/migration_timeline.puml) — диаграмма Ганта (PlantUML) с этапами миграции.
