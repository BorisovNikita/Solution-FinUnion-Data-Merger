# Доменные data-продукты (элементы Data Mesh)

В целевой архитектуре элементы Data Mesh применяются для выделения ключевых наборов данных как самостоятельных продуктов, которыми владеют бизнес-домены.

|Data product|Домен (BIAN)|Основные данные|Владелец|Потребители|
|-|-|-|-|-|
|**Customer 360**|Party Data Management|Профиль клиента (ФИО, ИНН, контакты), сегмент, согласия, история взаимодействий.|Data Office / CRM-домен|CRM, BI, Маркетинг, Риск-менеджмент|
|**Transactional Fraud Monitor**|Transaction Processing|Агрегированные транзакции, отклоненные операции, паттерны аномалий.|Риск-менеджмент / Антифрод|Служба безопасности, Контакт-центр, Регулятор|
|**Credit Portfolio Risk**|Loan Management|Кредитные договоры, остатки долга, просрочки, скоринговые баллы.|Кредитный департамент|Финансовый департамент, Регулятор, BI|
|**Product Performance**|Product Catalog|Данные о продажах продуктов, тарифах, комиссиях, доходности.|Продуктовый департамент|Маркетинг, Финансы, Топ-менеджмент|
|**Branch Performance**|Branch Management|Метрики работы департаментов (филиалов): количество обращений, время обслуживания, NPS.|HR / Операционный департамент|Топ-менеджмент, BI|
