# Риски миграции

|Риск|Влияние|Вероятность|Митигация|
|-|-|-|-|
|**Дубли клиентов**|Ошибки в профиле, неверные коммуникации, сбои в обслуживании|Высокая|Правила нечёткого сравнения (Fuzzy Matching), ручная верификация спорных случаев, пилотный запуск на ограниченной выборке.|
|**Потеря исторических данных**|Невозможность построить отчётность за прошлые периоды, регуляторные риски|Средняя|Полное резервное копирование перед миграцией, выгрузка архивов в Lakehouse, сверка контрольных сумм.|
|**Простой операционных систем**|Остановка обслуживания клиентов, финансовые потери|Низкая (при поэтапном подходе)|Поэтапная миграция, cutover в непиковые часы, резервные каналы, фолбэк-план.|
|**Несинхронизированные справочники**|Ошибки в отчётности, неверная маршрутизация обращений|Средняя|Централизация НСИ в MDM, версионность (SCD2), обязательная валидация при загрузке.|
|**Задержка синхронизации MDM с CRM**|Менеджеры видят устаревшие данные, ошибки в продажах|Средняя|Настройка SLA (≤5 мин), мониторинг задержек, алертинг, использование Kafka для Near Real-Time.|
|**Сопротивление бизнес-пользователей**|Снижение эффективности работы, ошибки из-за непривычного интерфейса|Средняя|Обучение, вовлечение бизнеса на этапе проектирования, пилотные группы, поддержка Change Manager.|
|**Утечка ПДн при миграции**|Нарушение 152-ФЗ, репутационные потери, штрафы|Низкая|Шифрование каналов, маскирование данных в тестовых средах, RBAC, аудит доступа, согласование с ИБ.|
