# Task 2: Мастер-системы, владение данными и потоки данных

## Описание решения

В рамках второго задания определены мастер-системы для ключевых сущностей в промежуточном (3 месяца) и целевом состояниях, описаны правила владения данными (Data Ownership), построена контекстная диаграмма потоков данных (DFD Level 0), а также составлена матрица управления потоками и выявлены проблемные зависимости.

## Структура директории

* [**master-systems.md**](./master-systems.md) — матрица мастер-систем с привязкой к BIAN.
* [**data-ownership.md**](./data-ownership.md) — роли Data Owner, Data Steward, Producer и Consumer.
* [**data-flows.md**](./data-flows.md) — описание логических потоков данных между системами.
* [**data-flow-management.md**](./data-flow-management.md) — операционная таблица управления потоками (SLA, частота, безопасность).
* [**data-dependencies.md**](./data-dependencies.md) — реестр рисков и проблемных зависимостей.
* [**diagrams/data-flow.puml**](./diagrams/data-flow.puml) — код DFD-диаграммы (PlantUML).
