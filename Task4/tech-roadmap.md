# Технологическая дорожная карта

|Зона|Технологии / подходы|Обоснование|
|-|-|-|
|**Adopt** (внедряем)|MDM Customer Hub, Airflow, DWH на PostgreSQL (промежуточный), DataHub (каталог), Integration Layer (ESB), Kafka, Data Lakehouse (Iceberg + Trino), BI|Это ядро целевой архитектуры. Технологии зрелые, команда имеет компетенции или может быстро обучиться. Обеспечивают выполнение требований по отчётности, lineage и разделению OLTP/OLAP.|
|**Trial** (пилотируем)|Потоковая обработка (Kafka Streams / Spark Streaming), Apache Iceberg для ACID на озере, Trino для федеративных запросов|Требуют пилотного проекта для проверки производительности и надёжности в банковском кейсе. Планируется запуск на исторических данных карточных операций.|
|**Assess** (оцениваем)|Полноценный Data Mesh (децентрализованное владение доменами), графовая БД (Neo4j) для анализа связей|Потенциально полезны, но требуют зрелой Data Culture и дополнительных ресурсов. Пока внедряем только элементы Data Products, а графовую БД оцениваем для антифрода.|
|**Hold** (воздерживаемся)|Замена всех legacy-систем за один шаг, отказ от DWH в пользу только Lakehouse, NoSQL для операционных данных|Противоречит ограничениям (нельзя останавливать сервисы, нужна ACID для финансовых данных). Откладываем до стабилизации целевой архитектуры.|
