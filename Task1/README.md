# Task 1: Анализ данных, сущностей, критичности и типов хранилищ

## Описание решения

В рамках первого задания проведен анализ As-Is ландшафта FinUnion и RetailBank. Целью работы было выделить ключевые бизнес-сущности, построить логическую модель данных, классифицировать информацию по уровню критичности и требованиям ИБ, а также предложить целевую стратегию хранения данных.

## Структура директории

* [**entities.md**](./entities.md) — реестр из 11 ключевых бизнес-сущностей с описанием атрибутов, источников и проблем качества данных.
* [**logical-data-model.md**](./logical-data-model.md) — логическая ER-модель связей между сущностями (Mermaid).
* [**data-classification.md**](./data-classification.md) — матрица классификации данных по категориям, критичности и средствам защиты.
* [**storage-strategy.md**](./storage-strategy.md) — предложенная гибридная архитектура хранения (OLTP, MDM, DWH, Data Lakehouse и др.) с обоснованием выбора и отказа от технологий.
* [**reference-model.md**](./reference-model.md) — сопоставление сущностей с референсной моделью BIAN для унификации доменов данных.
* [**diagrams/**](./diagrams/) — директория для хранения файлов диаграмм.
